# family-hackathon

가족해커톤(3차시) 운영용 안내·타이머 웹앱. 빌드 없는 정적 사이트로, GitHub Pages에 그대로 올릴 수 있다.

- `index.html` 첫 화면
- `stage.html` 무대 PC용 안내·타이머 (스페이스 시작/멈춤, ←/→ 단계 이동, R 리셋, F 전체 화면)
- `guide.html` 가족 노트북용 단계 안내, 2차시 Gemini 프롬프트 만들기
- `config.js` 차시·단계·시간·문구·선택지 (여기만 고치면 된다)
- `common.js` 휴식 끼워 넣기, 안전한 localStorage 접근

## 원칙
- 학생·보호자 입력은 서버로 보내지 않는다. 브라우저에만 임시 보관되며 게스트 로그아웃 시 사라진다.
- 단계는 순서 번호가 아니라 `id`로 구분한다.
- 기존 프로젝트(`5g_해커톤`, `1024_family3dpen`)의 소스·DB·배포 설정은 가져오지 않았다.
- 제출·갤러리 화면은 제출 방식 확정 후 추가한다.

## 로컬 확인
```
python -m http.server 8000
```
브라우저에서 `http://localhost:8000` 접속.
